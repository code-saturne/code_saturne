Code_Saturne Documentation
==========================

Code_Saturne is a general purpose CFD tool developed by EDF R&D.
It solves the Navier-Stokes equations for 2D or 3D flows, steady or unsteady,
laminar or turbulent, incompressible or weakly compressible.
