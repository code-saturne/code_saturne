Variables et Proprietes
=======================

Variables turbulentes
---------------------

* ``alpha`` : Variable elliptique EBRSM (-)
* ``epsilon`` : Taux de dissipation (m2/s3)
* ``k`` : Energie cinetique turbulente (m2/s2)
* ``nu_tilda`` : Viscosite turbulente modifiee (m2/s)
* ``omega`` : Taux de dissipation specifique (1/s)
* ``phi`` : Variable elliptique v2f (m2/s2)
* ``r11`` : Variable turbulente
* ``r12`` : Variable turbulente
* ``r13`` : Variable turbulente
* ``r22`` : Variable turbulente
* ``r23`` : Variable turbulente
* ``r33`` : Variable turbulente
* ``rij`` : Tenseur de Reynolds (m2/s2)
