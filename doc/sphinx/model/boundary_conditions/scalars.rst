Conditions aux limites des scalaires
=====================================

Types de BC scalaires
---------------------

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - Type
     - Description
   * - ``dirichlet``
     - Valeur imposee (Dirichlet)
   * - ``neumann``
     - Flux impose (Neumann)
   * - ``dirichlet_formula``
     - Valeur imposee via formule MEG
   * - ``dirichlet_implicit``
     - Dirichlet implicite (couplage)
   * - ``neumann_implicit``
     - Neumann implicite (couplage)
